   # Skybrisk Month 1 - Contact Book

   A command-line Contact Book application built in Python for the Skybrisk internship (Month 1: Python Fundamentals).

   ## Features
   - Add a contact (name, phone, email)
   - View all saved contacts
   - Search for a contact by name

   ## How to run
   python contact_book.py

   Contacts are stored in a text file (contacts.txt) in the same folder.
